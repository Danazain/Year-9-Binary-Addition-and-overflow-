Mission briefing

By the end, you should be able to add two 8-bit numbers using carries, check the calculation in denary, and explain when an 8-bit result overflows.

  • Mission 2: Arcade byte simulator (7 min)

  • Mission 4: Overflow detective (10 min)

Mission 2 · 7 minutes · 3 marks

Arcade byte simulator

Scenario from the slides: a player has 200 points and receives 100 bonus points. The arcade stores only one byte, and displays 44. Investigate why.

The red ninth bit is not stored in the 8-bit register. Read the weights 128, 64, 32, 16, 8, 4, 2, 1.

Mission 3 · 10 minutes · 8 marks

Carry challenges

Work from right to left. If a column totals 2, write 0 and carry 1. If it totals 3, write 1 and carry 1. Write all eight bits, including leading zeroes.

Mission 4 · 10 minutes · 8 marks

Overflow detective

An unsigned one-byte register stores numbers from 0 to 255. If the sum exceeds 255, the ninth bit is discarded and the eight rightmost bits remain.
